# 《惊鸿录》战斗系统策划调参与 Debug 说明文档

## 0. 文档用途

本文档用于说明当前战斗系统中，策划可以调整的参数、各参数含义、常见 Debug 日志含义，以及测试时应如何反馈问题。

当前战斗系统主要包括：

- 普通攻击：轻击 / 重击 / 远程 / 突刺
- 笔画槽
- 剑招释放
- 识破选择
- 重击蓄力与霸体
- 玩家被打断
- 敌人受击僵直
- 完美闪避基础检测
- 敌人 AI 基础行为

---

# 1. 普通攻击配置说明

普通攻击配置主要在 `SkillData` 资源中调整。

目前四个基础技能为：

| 技能 | 按键     | 笔画 | 资源                       |
| ---- | -------- | ---- | -------------------------- |
| 轻击 | 鼠标左键 | 撇   | `Basic_Horizontal.asset`   |
| 重击 | E        | 竖   | `Basic_Vertical.asset`     |
| 远程 | Q        | 横   | `Basic_LeftFalling.asset`  |
| 突刺 | 鼠标右键 | 捺   | `Basic_RightFalling.asset` |

---

## 1.1 Direction / 方向参数

### Direction Mode

决定技能释放方向。

当前有三种模式：

| 模式               | 含义                                   | 当前用途           |
| ------------------ | -------------------------------------- | ------------------ |
| `FacingHorizontal` | 根据角色当前面朝方向，只水平释放       | 轻击 / 重击 / 远程 |
| `MouseHorizontal`  | 根据鼠标在角色左侧还是右侧，只水平释放 | 突刺               |
| `AimDirection2D`   | 完整朝鼠标方向，可斜向 / 上下          | 当前暂不使用       |

当前策划规则：

- 轻击：角色面朝方向
- 重击：角色面朝方向
- 远程：角色面朝方向
- 突刺：鼠标左右方向，但没有 Y 轴

注意：

- `MouseHorizontal` 不是完整鼠标方向。
- 鼠标在玩家右侧，突刺向右。
- 鼠标在玩家左侧，突刺向左。
- 鼠标在上方或下方，不会导致上下突刺。

---

## 1.2 Timing / 时间参数

### Cooldown

技能冷却时间。

表示技能释放后，多久才能再次释放同一个技能。

例如：

```text
Cooldown = 0.8
```

表示该技能释放后 0.8 秒内不能再次释放。

------

### Cast Time

技能前摇时间。

流程：

```text
按下按键
→ 等待 Cast Time
→ 技能真正执行 / 生成判定 / 生成 Projectile / 开始 Dash
```

如果 Cast Time 太大，玩家会感觉“按了没反应”。

常见调法：

- 轻击：应较短
- 重击：可以稍长
- 远程：中等
- 突刺：太长会显得笨重

------

### Hitbox Duration

技能判定持续时间。

表示 Hitbox / 攻击判定存在多久。

例如：

```text
Hitbox Duration = 0.2
```

表示攻击判定持续 0.2 秒。

注意：

- 这个不是动画时长。
- 这是实际能打到敌人的判定窗口。
- 判定太短可能打不中。
- 判定太长可能显得过强。

------

### Recovery Time

技能后摇时间。

流程：

```text
技能执行结束
→ 进入 Recovery Time
→ 后摇结束后回到正常操作
```

后摇期间当前规则：

- 一般不能继续普通攻击
- 一般不能移动 / 跳跃
- 可以按 R 尝试释放剑招

如果 Recovery Time 太长，技能会显得笨重。

------

## 1.3 Charge / 蓄力参数

主要用于重击。

### Charge Until Release

是否按住蓄力，松开释放。

当前：

- 重击：开启
- 轻击 / 远程 / 突刺：关闭

如果没有勾选，则下面的蓄力参数通常不生效。

------

### Min Charge Time

最小蓄力时间。

表示玩家至少需要蓄力多久，才允许释放蓄力技能。

当前重击建议：

```text
Min Charge Time = 0.2
```

如果这个值太大，玩家会觉得重击松手不灵敏。

------

### Max Charge Time

最大蓄力时间。

当前重击建议：

```text
Max Charge Time = 1.5
```

超过这个时间后，蓄力值不再增加。

当前阶段暂未实现：

- 蓄力越久伤害越高
- 蓄力越久破韧越高

目前只是限制最大蓄力时间。

------

### Lock Movement While Charging

蓄力期间是否锁定移动。

当前重击应开启。

------

### Block Other Skills While Charging

蓄力期间是否禁止释放其他技能。

当前重击应开启。

------

### Super Armor While Charging

蓄力期间是否霸体。

当前策划规则：

```text
重击只有蓄力阶段霸体，其他阶段可被打断。
```

所以重击应开启该项。

------

## 1.4 Damage / 伤害参数

### Damage

技能基础伤害。

当前配置：

| 技能 | Damage |
| ---- | ------ |
| 轻击 | 10     |
| 重击 | 15     |
| 远程 | 10     |
| 突刺 | 5      |

注意：

当前还没有完整防御、护盾、破韧收益公式。
如果后续要做护盾敌或破韧，需要额外接入。

------

## 1.5 Hitbox / 判定范围参数

### Hitbox Size

攻击判定大小。

当前配置：

| 技能 | Hitbox Size |
| ---- | ----------- |
| 轻击 | 0.6 x 0.4   |
| 重击 | 1.0 x 1.0   |
| 远程 | 0.2 x 0.2   |
| 突刺 | 1.2 x 0.8   |

调参建议：

- 打不中：适当增大 Hitbox Size
- 太容易打中：适当减小 Hitbox Size
- 突刺太强：优先减少宽度或后摇，而不是随意改伤害

------

### Hitbox Offset

攻击判定相对于角色的位置偏移。

通常用于让攻击判定出现在角色前方。

注意：

- X 偏移会根据角色朝向自动翻转。
- 不建议随便把 Y 调太高或太低，否则看起来会打空气。

------

### Hitbox Shape

判定形状。

常见可能有：

- Box
- Circle
- Arc

当前多数普通攻击可以先用 Box。

------

## 1.6 Hit Stun / 敌人受击僵直

### Can Apply Hit Stun

是否让敌人进入短暂受击僵直。

当前配置：

| 技能 | Can Apply Hit Stun |
| ---- | ------------------ |
| 轻击 | true               |
| 重击 | true               |
| 远程 | true               |
| 突刺 | false              |

------

### Hit Stun Duration

敌人受击僵直时间。

当前配置：

| 技能 | Hit Stun Duration |
| ---- | ----------------- |
| 轻击 | 0.1               |
| 重击 | 0.2               |
| 远程 | 0.1               |
| 突刺 | 0                 |

注意：

0.1 秒很短，如果没有动画 / 闪白 / 音效，肉眼不一定明显。
测试机制时可以临时改成 0.5 秒，看是否真的生效。

# 2. 远程 Projectile 配置说明

远程技能使用 `ProjectileData`。

当前主要资源：

```text
Projectile_Basic_LeftFalling.asset
```

## 2.1 Speed

Projectile 飞行速度。

当前配置：

```text
Speed = 2
```

如果感觉远程飞行物太慢，可以反馈策划确认是否提高。

------

## 2.2 Lifetime

Projectile 存活时间。

当前配置：

```text
Lifetime = 3
```

表示飞行物 3 秒后自动销毁。

------

## 2.3 Destroy On First Hit

命中第一个敌人后是否销毁。

当前建议：

```text
Destroy On First Hit = true
```

表示远程不可穿透敌人。

------

## 2.4 Destroy On Impact

撞到地面 / 墙体后是否销毁。

当前建议：

```text
Destroy On Impact = true
```

------

## 2.5 Impact Check Radius

Projectile 检测碰撞的半径。

当前配置：

```text
Impact Check Radius = 0.1
```

如果飞行物容易穿墙或撞不到墙，可以检查这个值。

# 3. Dash / 突刺配置说明

突刺使用 `DashData`。

当前主要资源：

```text
Dash_Basic_RightFalling.asset
```

## 3.1 Duration

突刺持续时间。

当前配置：

```text
Duration = 0.2
```

表示真正位移 / 判定阶段持续 0.2 秒。

------

## 3.2 Distance

突刺距离。

距离越大，突刺位移越远。

如果突刺太猛，优先调低 Distance。
如果突刺太短，优先调高 Distance。

------

## 3.3 Invincible During Dash

突刺期间是否无敌。

当前策划规则：

```text
突刺全程霸体 / 不被打断
突刺位移期间应具有无敌或至少不受伤
```

当前 Dash 位移阶段应开启：

```text
Invincible During Dash = true
```

注意：

如果策划要求“突刺从按下开始全程霸体”，还需要程序收口打断窗口。
当前已确认需要后续按“突刺全程霸体”收口。

------

# 4. 玩家被打断规则说明

当前打断逻辑由 `PlayerInterruptReceiver` 控制。

## 4.1 当前策划确认规则

当前确认规则：

| 行为            | 是否可被打断       |
| --------------- | ------------------ |
| 轻击            | 全程可被打断       |
| 远程            | 全程可被打断       |
| 重击蓄力        | 不可被打断，霸体   |
| 重击释放 / 后摇 | 可被打断           |
| 突刺            | 全程霸体，不被打断 |
| 剑招            | 全程霸体，不被打断 |

------

## 4.2 Heavy 攻击

敌人攻击有 `AttackInterruptType`：

| 类型  | 含义                     |
| ----- | ------------------------ |
| None  | 不打断                   |
| Light | 轻攻击，不打断玩家普攻   |
| Heavy | 重攻击，可以打断玩家普攻 |

当前测试敌人的近战攻击是：

```text
InterruptType = Heavy
```

敌人远程鱼叉目前是：

```text
InterruptType = None
```

------

## 4.3 PlayerInterruptReceiver 调试参数

### logInterruptDebug

是否打印成功打断日志。

建议测试时开启。

------

### logInterruptRejectReason

是否打印“为什么没有打断”。

建议测试时开启。

------

### debugOverrideInterruptedStunDuration

调试用的打断僵直时长覆盖。

含义：

```text
小于等于 0：使用正式 interruptedStunDuration
大于 0：使用该调试时长
```

测试时可以设为：

```text
1.0
```

这样被打断后玩家会明显卡住 1 秒，方便观察。

正式版本建议改回：

```text
-1
```

或：

```text
0
```

------

## 4.4 interruptedStunDuration

正式玩家被打断后的僵直时间。

当前建议：

```text
0.25
```

表示玩家被打断后 0.25 秒不能操作。

------

# 5. Debug 日志含义

## 5.1 玩家打断日志

### `[PlayerInterrupt] Interrupt success. Skill=轻击, Duration=1`

含义：

```text
玩家当前正在释放轻击
受到了 Heavy 攻击
成功被打断
进入 1 秒调试僵直
```

如果 Duration 是 1，说明当前启用了 `debugOverrideInterruptedStunDuration = 1.0`。

------

### `[PlayerSkill] Cast interrupted. Skill=轻击`

含义：

```text
PlayerSkillController 收到打断请求
当前释放中的轻击被取消
后续判定不会继续生成
```

------

### `[PlayerInterrupt] Player interrupt stun started. Duration=1`

含义：

```text
玩家进入被打断僵直
此期间不能移动、跳跃、普攻、剑招
```

------

### `[PlayerInterrupt] Player interrupt stun ended.`

含义：

```text
玩家打断僵直结束
恢复正常操作
```

------

### `[PlayerInterrupt] Ignore: player is not casting or charging.`

含义：

```text
玩家被 Heavy 攻击命中
但玩家当前没有在释放技能或蓄力
所以不触发“打断普攻”
```

这是正常情况。

例如：

- 玩家待机被打
- 玩家移动中被打

玩家会正常受伤，但不会进入“普攻打断逻辑”。

------

### `[PlayerInterrupt] Ignore: player has super armor.`

含义：

```text
玩家当前处于霸体状态
所以不会被打断
```

常见于：

```text
重击蓄力阶段
```

------

### `[PlayerInterrupt] Ignore: player is dashing.`

含义：

```text
玩家当前正在 Dash / 突刺位移
所以不被打断
```

------

### `[PlayerInterrupt] Ignore: interrupt type is None, not Heavy.`

含义：

```text
这次伤害不是 Heavy 攻击
所以不触发玩家普攻打断
```

常见于：

- 敌人远程鱼叉
- 普通非打断伤害
- 环境伤害

------

## 5.2 敌人攻击日志

### `Dummy_Enemy attacked.`

含义：

```text
敌人执行了一次近战攻击
生成了敌人近战 Hitbox
```

如果玩家靠近敌人但一直没有这条日志，说明敌人没有进入攻击逻辑。

------

### `Dummy_Enemy threw a harpoon.`

含义：

```text
敌人执行了一次远程攻击
生成了鱼叉 Projectile
```

------

## 5.3 敌人受击僵直日志

### `Dummy_Enemy action interrupted by hit stun.`

含义：

```text
敌人受到玩家攻击
进入受击僵直
当前 AI 行为被打断
```

------

### `Dummy_Enemy hit stun ended, AI resumed.`

含义：

```text
敌人受击僵直结束
AI 恢复行动
```

------

## 5.4 敌人浮空日志

### `Dummy_Enemy action interrupted by airborne.`

含义：

```text
敌人被击飞 / 浮空
当前 AI 行为被打断
```

------

### `Dummy_Enemy airborne ended, AI resumed.`

含义：

```text
敌人浮空结束
AI 恢复行动
```

------

## 5.5 完美闪避日志

PerfectDodgeTrigger 碰到了可完美闪避的敌人攻击 Hitbox

# 6. 笔画槽调试说明

当前笔画槽为 7 格。

规则：

1. 普通攻击成功执行后记录笔画。
2. 最多保留 7 个笔画。
3. 超过 7 个时，最早的笔画会被挤出。
4. 每隔一段时间会自然移除最早的笔画。
5. 剑招释放时会消耗对应笔画。
6. 当前剑招匹配可以无序计数。

当前普通攻击对应笔画：

| 技能 | 笔画 |
| ---- | ---- |
| 轻击 | 撇   |
| 重击 | 竖   |
| 远程 | 横   |
| 突刺 | 捺   |

------

## 6.1 常见笔画日志

### `当前笔画槽：撇 横 竖`

含义：

```text
当前玩家已经记录的笔画序列
```

如果技能被打断且没有真正执行，不应该记录笔画。

------

## 6.2 策划需要重点测试

1. 技能被打断时，是否不记录笔画。
2. 技能成功释放时，是否记录对应笔画。
3. 剑招释放后，是否只消耗需要的笔画。
4. 多余笔画是否保留。
5. 7 格满后，是否挤出最早笔画。

------

# 7. 识破系统调试说明

识破系统用于多个剑招同时满足时，让玩家选择释放哪个剑招。

## 7.1 触发条件

当多个剑招都满足释放条件时，按 R 会进入识破。

------

## 7.2 当前规则

1. 进入识破时暂停战斗。
2. 玩家可以用鼠标点击候选剑招。
3. 点击后释放对应剑招。
4. R / Esc 可以取消识破。
5. 超时也会退出识破。
6. 取消 / 超时不会消耗笔画。
7. 确认释放才会消耗笔画。

------

## 7.3 常见日志

### `Insight item clicked: 剑招：长生诀`

含义：

```text
玩家点击了识破 UI 中的一个候选项
```

------

### `Insight view received click: 剑招：长生诀`

含义：

```text
识破 UI 收到了点击事件
```

------

### `Insight confirmed: 剑招：长生诀`

含义：

```text
识破系统确认选择该剑招
```

------

### `Released sword art from insight: 剑招：长生诀`

含义：

```text
该剑招从识破选择中成功释放
```

------

# 8. 剑招配置说明

剑招配置在 `SwordArtData` 中。

## 8.1 Required Sequence

剑招需要的笔画配方。

例如：

```text
横 横 撇 捺
```

------

## 8.2 Match Mode

当前支持：

| 模式            | 含义                       |
| --------------- | -------------------------- |
| OrderedTail     | 按顺序匹配最后若干笔画     |
| UnorderedCounts | 不看顺序，只看数量是否满足 |

当前策划需求主要使用：

```text
UnorderedCounts
```

例如：

```text
11223
```

表示玩家只要在 7 格槽里拥有：

```text
两个 1
两个 2
一个 3
```

即可满足，不要求顺序。

------

## 8.3 Cooldown

剑招冷却时间。

------

## 8.4 Execution Delay

剑招匹配成功后，延迟多久执行效果。

用于表现：

```text
按下释放
→ 播放起手动画
→ 延迟后真正生成剑招效果
```

# 9. 敌人 AI 参数说明

敌人行为主要在 `EnemyData` 中调整。

## 9.1 Attack Range

敌人近战攻击范围。

玩家进入该范围后，敌人会尝试近战攻击。

------

## 9.2 Aggro Range

敌人发现玩家并追击的范围。

玩家在该范围内，且不在攻击范围内时，敌人会追击。

------

## 9.3 Lose Target Range

玩家距离超过该范围后，敌人停止追击。

------

## 9.4 Stop Distance

敌人追击时的停止距离。

当前程序中已经做了保护：

```text
实际停止距离 = min(StopDistance, AttackRange * 0.8)
```

避免敌人停在攻击范围外。

------

## 9.5 Preferred Min Distance / Preferred Max Distance

用于敌人战斗间距控制。

当前注意：

```text
PreferredMaxDistance 不再作为近战敌人硬停止条件
```

否则会导致敌人在攻击范围外发呆。

------

## 9.6 Backstep 参数

敌人后撤参数。

当前存在 TODO：

```text
敌人可能后撤出屏幕
```

后续需要加：

- 战斗区域边界
- 后撤最大范围
- 屏幕 / 场景限制

# 11. 策划测试反馈模板

测试时请尽量按下面格式反馈。

## 11.1 普通攻击反馈

```text
技能：
问题：
期望：
实际：
是否能复现：
截图 / 录屏：
```

示例：

```text
技能：突刺
问题：按下后前摇太长，感觉不灵敏
期望：右键后更快开始位移
实际：按下后约 0.3 秒才动
是否能复现：稳定复现
```

------

## 11.2 打断反馈

```text
玩家状态：
敌人攻击类型：
期望是否被打断：
实际是否被打断：
Console 日志：
```

示例：

```text
玩家状态：重击蓄力
敌人攻击类型：近战 Heavy
期望是否被打断：不被打断
实际是否被打断：没有被打断
Console 日志：[PlayerInterrupt] Ignore: player has super armor.
```

```text
敌人：
玩家位置：
敌人当前行为：
期望行为：
实际行为：
是否能复现：
```

示例：

```text
敌人：Dummy_Enemy
玩家位置：敌人右侧，攻击范围外一点
敌人当前行为：原地不动
期望行为：继续追击
实际行为：原地停住
是否能复现：稳定复现
```

# 12. 不建议策划直接修改的内容

以下内容不建议直接修改，除非和程序确认：

1. Script 引用
2. LayerMask
3. TeamId
4. Player / Enemy prefab 结构
5. Hitbox2D 初始化逻辑
6. DamageInfo 字段
7. PlayerControlLock 配置
8. Scene 中核心对象引用
9. EventSystem
10. TimeScaleController

这些内容改错后可能导致：

- 技能无效
- 打不到敌人
- 敌人打不到玩家
- UI 点不了
- 识破无法退出
- 玩家无法操作
- 场景引用丢失
